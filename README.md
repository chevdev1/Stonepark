# STONEPARK

8-битный андеграунд-лендинг: живая общая стена для граффити, команда персонажей с диалогами, квесты, ачивки, перекур, Джонник, музыка, галерея, хроника, манифест и роадмап.

Как выложить в GitHub и на свой сервер: см. **DEPLOY.md**.

## Быстрый старт

Нужен любой статический сервер (открывать `index.html` двойным кликом не стоит: браузер заблокирует часть функций).

**Вариант 1. VS Code + Live Server**
1. Открой папку `stonepark` в VS Code.
2. Установи расширение **Live Server** (Ritwick Dey), VS Code сам его предложит.
3. Правый клик по `web/index.html` → **Open with Live Server**.

**Вариант 2. Терминал**
```bash
cd web
python3 -m http.server 8080
# открой http://localhost:8080
```
или `npx serve web`.

Чтобы проверить стену и чат «на несколько человек», открой сайт в двух вкладках: штрихи, сообщения и курсоры синхронизируются между ними.

Для ранкеда открой вкладки как разные люди: `http://localhost:8080/?as=anna&rkfast` и `http://localhost:8080/?as=boris&rkfast` (и третью `?as=fan&rkfast` для голосования). `rkfast` делает раунд 15 секунд рисования и 20 секунд голосования. TRUE OG открывается в окне ачивок кнопкой «Тест владельца: открыть всё».

## Где что менять в `app.js`

Файл поделён на блоки, ищи по заголовкам `// =====`:

| Блок | Что внутри |
|---|---|
| `i18n` | все тексты интерфейса RU и EN (объект `T`) |
| `WALL` | стена 3840×2160: камера, рисование, подтёки, синхронизация, карта |
| `WALL: nickname + chat` | ник и чат стены, правила чата |
| `MUSIC` | ящик с пластинками, редактор треков владельца |
| `CHRONICLE` | видео (объект `VIDEOS`) |
| `GALLERY` | галерея, лайтбокс, добавление работ |
| `STORY` | персонажи (`CHAR`), реплики, вступление CH, квесты, пейджер, звуки (`SFX`) |
| `DOPE + smoke sessions` | доуп, перекур, «убитые» реплики (`STONED`) |
| `ACHIEVEMENTS` | список ачивок (`ACH_DEF`, `ACH_TXT`) |
| `JOHNNY` | собака: ходьба, реакции |
| `HERO` | WebGL-шейдеры сцены (НЕОН / CRT / ВЫКЛ) |
| `RANKED` | батлы «кусок на кусок»: вызовы, арена, голосование, рейтинг (константы времени в `RK`) |
| `TRUE OG` | разблокировка за все ачивки, вайбы (`VIBES`), атласы сцены (`ATLAS`) |
| `INSPECT` | осмотр предметов на фоне, комикс-пузыри (`LOOK`) |
| `boot` | подключение к базе и остальным функциям |

Реплики персонажей лежат в `STORY.ru.lines` и `STORY.en.lines`. Реплика может быть строкой или объектом:
`{ text: '…', sub: { ru: 'перевод', en: 'translation' }, video: 'skate' }`
— `sub` даёт перевод мелким шрифтом (так говорит YUZU), `video` добавляет кнопку «▶ Смотреть».

## Перерисовать графику

```bash
cd tools
pip install -r requirements.txt
python make_art.py              # всё: портреты, контуры, «убитые» кадры, карточки, Джонник, сцена
python make_art.py portraits    # только персонажи
python make_art.py scene        # только сцена (около минуты)
# сцены с TRUE OG и вайбами: в scene2.py поставь OG = True и VIBE = 'clan' | 'winter' | 'party'
```
Поменял цвет куртки в `chars.py` → запустил → обновил страницу.

Музыка: `python lofi.py` создаёт `stonepark_lofi.wav`, затем
`ffmpeg -i stonepark_lofi.wav -b:a 160k ../web/assets/audio/stonepark_lofi.mp3`.

## Что работает локально, а что нужно для публичного запуска

На claude.ai страница получает от платформы общую базу, живое присутствие, личность посетителя, загрузку файлов и доступ к Claude. Файл `js/local-runtime.js` заменяет всё это локальными версиями с теми же методами:

| Функция | На claude.ai | Локально (`local-runtime.js`) | Для публичного сайта |
|---|---|---|---|
| Стена, чат, треки, галерея, респекты (`db`) | общая база | localStorage + синхронизация вкладок | Supabase, Firebase или свой API |
| Курсоры и «N у стены» (`room`) | живое присутствие | между вкладками | Supabase Realtime / WebSocket |
| Владелец, ник, имена (`user`) | аккаунт claude.ai | ты всегда владелец | авторизация (например, через Telegram) |
| Загрузка обложек и работ (`assets`) | хранилище артефакта | в localStorage (маленькие файлы) | Supabase Storage / S3 |
| Пейджер CH «вживую» (`sample`) | Claude от лица CH | заготовленные ответы | свой сервер с Claude API (ключ только на сервере!) |
| Сохранить стену в PNG (`downloads`) | диалог сохранения | обычное скачивание | так же |

### Свой бэкенд
Ничего в `app.js` переписывать не нужно. Сделай свой файл, например `js/supabase-runtime.js`, который объявляет `window.claude = { use: async (name) => …, assetUrl: (id) => … }` с теми же методами, что в `local-runtime.js`:

- `db.collection(path).orderBy(field, dir).limit(n).onSnapshot(cb)` → `cb({ docChanges(), forEach() })`
- `db.collection(path).doc(id).set(data) / .delete()`, `db.doc('a/b').onSnapshot(cb) / .set(data)`
- `room.presence(obj)`, `room.onPeers(cb)` → `cb({ peers: [{ sameTab, presence }] })`
- `user.id()`, `user.canEdit()`, `user.can('data.write')`, `user.profiles(ids)`
- `assets.upload(file)` → `{ id }`, плюс `window.claude.assetUrl(id)` → url картинки
- `downloads.save({ filename, data })`

Подключи его в `index.html` вместо `local-runtime.js`. Коллекции, которые использует сайт: `megawall/<эпоха>/strokes`, `wall/state`, `chat`, `tracks`, `music/settings`, `gallery`, `shouts`, `props`, `battles`, `bstrokes/<батл>/s`, `bvotes`.

**Обязательно на сервере:** правила доступа (писать в `tracks`, `gallery`, `music`, `wall` может только владелец, остальное — авторизованные), лимит частоты для чата и штрихов, фильтр ссылок в чате продублировать на сервере.

## Деплой

Папка `web/` — обычный статический сайт: Vercel, Netlify, Cloudflare Pages или GitHub Pages. Перетащи папку или подключи репозиторий, сборка не нужна.

## Гостевой режим

На claude.ai писать в общую базу могут только участники вашей организации, остальные получают «только просмотр». Такие посетители автоматически попадают в гостевой режим: рисуют и пишут для себя (краска и сообщения хранятся в их браузере), а ачивки и все персонажи открываются как обычно. Для общей стены с людьми со всего интернета нужен свой бэкенд (раздел выше).

Подробная документация простым языком: STONEPARK — как устроен сайт (Claude Doc).

## Важные мелочи

- Вступление CH, ачивки, доуп, квесты и ник хранятся в браузере посетителя (localStorage). Чтобы снова увидеть вступление, открой сайт в режиме инкогнито или выполни в консоли `localStorage.clear()`.
- Кнопка «Анимации» в шапке перебивает системную настройку «уменьшить движение».
- Звук включается после первого клика (требование браузеров) и никогда не ломает интерфейс, даже если браузер не поддерживает WebAudio.
- Ссылку на Telegram для работ, профиль SoundCloud и launchpad владелец задаёт кнопкой «Настройки раздела».
